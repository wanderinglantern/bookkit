## 3. Decisions made today, with the reasoning

Full rulings ledger (R1–R66) is at
`.superpowers/sdd/2026-08-17-web-account-page/progress.md` — **gitignored, so it
does not travel between machines.** The load-bearing ones:

- **Revert ships refuse-only; force is deferred.** The TUI offers force behind a
  modal that previews the plan; the web has no such preview and inventing one
  unspecified is how this build has gone wrong before. The refusal names the
  conflicting fields and points at the TUI's `R`.
- **`hx-confirm` on both revert controls.** A revert cannot itself be reverted
  (`services/batches.revert` writes carry no batch_id), so a one-click
  irreversible control was not defensible. A designed confirm can replace it.
- **The timeline's subject is NOT inline-editable**, against the design
  prototype. `forms/inline.py` is shared with the TUI and declares nothing for
  interactions; a web-only inline set forks the surfaces on the one axis that
  file exists to prevent. Whole-form edit instead.
- **Interactions are read/edit/delete. No create.** `forms.entities` has only an
  EDIT builder; creation lives in quick capture. The `+ Log interaction` pill
  stays inert.
- **Contact removal is a REMOVE, not a deactivate.** Deactivation is a separate,
  broader records question — its own `ROADMAP.md` entry.
- **Removing a primary clears the flag and promotes nobody.** Picking a new
  primary is a judgment, not a side effect of a delete.
- **The wheelhouse was published under a NEW tag, not clobbered.** `install.sh`
  was byte-identical on main, so replacing v0.1.0's asset in place would have
  broken main's installer with a tamper warning about an untampered file.

## 4. Two bugs found today that shaped everything

**Concurrent requests shared one SQLite connection.** Every web route ran
against a single `app.state.conn` while FastAPI ran the sync routes in a
threadpool; Python's per-connection statement cache is not thread-safe.
Measured: 6 concurrent readers → 149 of 540 responses wrong, including 404 "no
such account" for accounts that exist; **81 of 2608 committed events recorded
`old_value = NULL`**, silently, HTTP 200 — and undo writes `old_value` back, so
Revert would have nulled a field that had data. Fixed by one connection per
thread, with an AST guard (`tests/test_conventions.py`) that fails the suite if
anyone `await`s inside a transaction, because the async write routes still share
the loop's connection and are safe only because they never suspend mid-batch.

**Found by refusing to shrug at a test that failed 1 run in 4.** That is the
lesson worth keeping.

**Nineteen web routes named an account AND a row; only one checked they belonged
together.** A stale or crafted URL removed a contact from a different account
than the page displayed, behind a confirm whose two lines named two different
clients. The merged cell routes wrote to other accounts' contacts, tasks and
request items the same way, and `requests/{id}/items/new` could CREATE an item
on another account's request. One guard in `routes/account.py` (`_owned`,
`_owned_item`, `_owns_raw_row`) now covers all eighteen; `tests/test_web_scoping.py`
drives every handler with account A's ref and account B's ids.

Exposure was low — loopback, single user — and nothing is known to have been
written wrongly.

## 5. Gotchas that cost real time

- **`uv run pytest` silently falls through to Anaconda's pytest** and reports
  `ModuleNotFoundError: No module named 'bookkit'`, looking exactly like a
  broken editable install. Always `uv run --no-sync python -m pytest`.
- **A fresh worktree needs `uv sync --group dev`.** A bare `uv sync` installs
  runtime deps only. After merging a branch that adds dependencies, the MAIN
  worktree needs it too — this bit us post-merge.
- **Background-task notifications report the WRAPPING shell command's exit code,
  not pytest's.** One reported exit 0 for a run that failed. Always redirect to
  a file and read the file.
- **htmx does not swap 4xx or 5xx**, and `inline-cell.js` registers no
  `htmx:responseError` listener. A route answering a rendered control with a
  bare `HTTPException` renders as **silence**. This bit three times.
- **htmx applies out-of-band swaps BEFORE the primary swap.** Returning an OOB
  panel plus a primary swap targeting something inside that panel detaches the
  target — the content lands in a node no longer on the page. Return the OOB
  panel alone.
- **Every batch ref is prefixed `MCP-`** regardless of source
  (`repo/batches.py:12`). A web-made change shows as `MCP-0001` with
  `source='web'`. Cosmetic, user-visible, unfixed — a rename would touch
  identifiers already in Grant's real book.

## 6. Process that worked, and should continue

Per task: extract a brief → dispatch an implementer → **run the gates yourself**
→ dispatch a reviewer → adjudicate → fix rounds → merge.

- **Every gate green does not mean the code is right.** Caught by review, never
  by a gate: a wheel that could not be built, a race letting two records share
  one undo unit, a click that discarded the edit being typed, a parity ledger
  blind to the feature it tracked, nested `<td>`s misaligning every column,
  four flows with no Cancel, and roughly eight tests that passed for a reason
  adjacent to what they claimed.
- **Mutation-prove every new test.** Break the production behaviour, watch the
  named test fail. A reviewer reporting which mutations PASSED — i.e. which
  behaviours nothing holds — was the single most useful artifact produced.
- **The briefs have been wrong repeatedly; the runtime reasoning has held.**
  Implementers pushed back with evidence and were right at least five times
  today (a cited file that did not exist, a test filter hiding three accounts, a
  `.get(k, k)` masking the bug its test existed to catch, a validation target
  that would have 404'd the default tab, an OOB fix shape that reproduced the
  bug it closed, a fixture date collision making an assertion vacuous). **When
  an implementer says the brief is wrong, check the code, not the brief.**
- **Never `git add -A`** — it swept an unrelated diff into a commit here once.
- **Never commit or dispatch a second agent while an implementer is live in the
  same worktree.**
- Playwright earned its keep: it caught bugs that markup-reading missed. Verify
  anything visual in a real browser.
